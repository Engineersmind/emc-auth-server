v1.1.0 2026-05-18
GitHub Release Diff

TOTP 2FA — Phase 3

  • Enroll: POST /api/v1/auth/otp/enroll — returns otpauth:// URI + 8 single-use backup codes
  • Activate: POST /api/v1/auth/otp/activate — validates first code, marks TOTP active
  • Disable: DELETE /api/v1/auth/otp — requires valid TOTP or backup code
  • Two-step login: POST /auth/login returns totp_session_id; POST /auth/login/otp completes auth
  • TOTP secrets encrypted at rest with AES-256-GCM; backup codes SHA-256 hashed, single-use

API Keys — Phase 3

  • Create: POST /api/v1/admin/api-keys — emck_ prefix, 32-byte random, raw shown once only
  • List: GET /api/v1/admin/api-keys — name, created_at, last_used (raw never returned again)
  • Revoke: DELETE /api/v1/admin/api-keys/:id
  • Auth via X-API-Key or Authorization: ApiKey <key> header; SHA-256 hash stored in DB
v1.0.0 2026-05-18
GitHub Release

Foundation — Phase 1 + 2

  • Go 1.23 + Echo v4, PostgreSQL 16 (pgx v5 + pgxpool), Redis 7, Goose migrations, Zerolog
  • User registration with bcrypt cost-12 and duplicate detection
  • Login with JWT HS256 (per-tenant secret), 1-hour access + 30-day refresh token
  • Atomic refresh rotation — old token revoked before new issued; replay returns 401
  • Password reset: SHA-256 token, 15-min TTL, enumeration-safe responses
  • Rate limiting: 5/min/IP + 10/min/tenant on login endpoint
  • Swagger UI at /swagger/index.html
  • 3-stage Docker build → distroless/static ~5MB final image
  • Single binary: migrations + seed embedded via embed.FS, boots in <1s
  • Security headers: HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy
